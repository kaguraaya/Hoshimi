# 界面设计规范

Hoshimi 的界面规则照搬自 FlClash（`chen08209/FlClash` 的 `.agents/surfaces.md` 与它的组件库 `chen08209/prism_ui`）。
实现都在 `app/src/main/java/com/acgcompass/core/designsystem/`。新写页面时按这里的规则来，不要在调用处自己挑颜色。

## 1. 用明度的台阶表达结构，不用描边

| 层级 | 浅色（明度） | 深色（明度） | 放什么 |
| --- | --- | --- | --- |
| 页面 `Page` | 94 的灰 | 6 | 页面底 |
| 卡片 `Card` | 98 的近白 | 15 | 卡片、成组的行 |
| 色块 `Block` | 94 的灰 | 21 | 卡片里的色块：未选中的选项、内嵌条目、输入框 |
| 内嵌 `Inset` | 90 | 27 | 色块里的小标记：图标底、徽章、进度轨、封面占位 |

- 浅色是「灰底页面上放近白卡片，卡片里再放灰色块」；深色只往亮处走。
- 每个表面取它所在表面的下一级，由 `SurfaceScope` 沿组件树传下去。`PrismCard`、`FlatCard`、选项、输入框都从
  `Surfaces.raisedColor` 取色——同一个组件放在页面上是白的，放进卡片里是灰的。
- **表面保持近灰**：壁纸取色或预设配色的表面色只保留色相、彩度压到很低（`prismColorScheme`）。颜色只留给
  「被选中、开启、出错、这一屏的主操作」。
- 主色容器 / 次色容器 / 第三色容器**不当卡片底色**，也不当选中态；色调按钮、底栏选中块都是中性色。
- 浮在内容上的东西（菜单、对话框、底栏、底部面板）浅色取卡片级、深色取色块级，并带投影；其余卡片没有投影。

## 2. 该描边的地方

只有这几处画线：

- **单独放在页面上的输入框**：描边、圆角 16，标签嵌在线框里（填充色在这里表示「结构」，填了色的输入框会被读成一张卡片）。
  放在卡片里的输入框不描边，取深一级的填充色。`FlatTextField` 会按所在层级自动选。
- **成组的行之间**：一条发丝线，颜色是 `onSurface` 的 14%（`FlatDivider`，在卡片里才画线，直接放在页面上只留间距）。
- 出错的卡片整张换成错误容器色，**不**加描边。

## 3. 选中与状态

- 互斥的分段选项、选项药丸：选中 = 实心主色 + `onPrimary`，未选中 = 深一级的中性色，都没有描边。
- 列表里的「当前项」用主色的标记（图标 / 文字变主色），不整行填色。底栏选中项是中性色块 + 主色图标文字。
- 标签徽章（`TagPill`）只是标识：中性底 + 次要字色。状态色（成功 / 警告 / 错误）只用在文字、图标或小徽章上。
- 文字：标题和数值用 `onSurface`，标签和次要行用 `onSurfaceVariant`；数值不染主色。

## 4. 尺寸

| 东西 | 值 |
| --- | --- |
| 圆角：徽章 / 输入框与分段选项 / 卡片里的色块 / 列表卡片与成组的行 / 带标题的分区卡片 | 8 / 16 / 20 / 24 / 32 |
| 按钮、选项药丸、底栏 | 全圆 |
| 页面左右留白 / 卡片间距 | 16 / 8 |
| 分区卡片内边距 | 左右 20、上下 18 |
| 卡片标题行 | 18dp 图标 + 8 间距 + 15/20 半粗标题 |
| 行高（至少）/ 行内左右边距 | 56 / 16 |
| 选项药丸高 / 分段选项高 | 36 / 44 |
| 分组标题 | 放在卡片外面，17/22 半粗、次要字色，左缘与卡片外缘对齐 |
| 字号档位 | 页面标题 24/30 · 标题 17/22 · 小标题 15/20 · 正文 16/22、14/20 · 说明 13/18 · 徽章 12/16，字间距 0 |

封面、内嵌块的圆角与外层卡片同心（外圆角 − 内边距）。

## 5. 按压

按下只有涟漪（状态层），**不缩放**、不变色块。

## 6. 验证

改完界面跑 `DeviceLikeScreenshotTest`：它用一套高饱和的壁纸取色配色和放大的字宽渲染首页、今晚看什么、导入、缓存、
「我的」等页面（带假封面和样例数据），图在 `app/build/outputs/roborazzi/device-*.png`。
重点看：有没有和所在表面同色的表面（漏了 `SurfaceScope`）、有没有残留的带色容器底、有没有被截断的文字。
